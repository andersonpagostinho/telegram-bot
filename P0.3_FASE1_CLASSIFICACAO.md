## 🎯 ESTRATÉGIA DE REFATORAÇÃO

Para cada uma das 17 linhas do **Grupo A**:

### Padrão 1: Resposta de Sucesso

```python
# ANTES:
await update.message.reply_text(mensagem, parse_mode="Markdown")
return True

# DEPOIS:
return {
    "ok": True,
    "acao": acao,
    "resultado": ...,
    "resposta": mensagem,
    "erro": None,
    "already_sent": False,
    "handled": True
}
```

### Padrão 2: Resposta de Erro

```python
# ANTES:
await update.message.reply_text("Erro: ...", parse_mode="Markdown")
return True

# DEPOIS:
return {
    "ok": False,
    "acao": acao,
    "resultado": None,
    "resposta": "Erro: ...",
    "erro": "motivo_do_erro",
    "already_sent": False,
    "handled": True
}
```

### Padrão 3: Return com reply (CRÍTICO)

```python
# ANTES:
return await update.message.reply_text(mensagem)

# DEPOIS:
return {
    "ok": True,
    "acao": acao,
    "resultado": ...,
    "resposta": mensagem,
    "erro": None,
    "already_sent": False,
    "handled": True
}
```

### Padrão 4: Resposta condicional (linha 619)

```python
# ANTES:
if update and update.message:
    await update.message.reply_text(mensagem)
else:
    print("[P0.2] esperando adapter")
return True

# DEPOIS:
return {
    "ok": True,
    "acao": acao,
    "resultado": ...,
    "resposta": mensagem,  # SEMPRE incluir
    "erro": None,
    "already_sent": False if not update else (True if update.message else False),
    "handled": True
}
```

## 🔐 Contrato `ResultadoAcao`

Reutilizar estrutura de `_send_and_stop()` com extensão:

```python
ResultadoAcao = {

    "already_sent": bool,      # True se foi enviado (Telegram)

    # Novos campos para completude

    "acao": str,               # Nome da ação
    "resultado": Any,          # Resultado da ação (evento criado, etc)

}
```
