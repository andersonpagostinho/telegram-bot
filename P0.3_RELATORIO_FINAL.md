## 📋 CONTRATO `ResultadoAcao`

```python
{
    "ok": bool,              # ✅ Sucesso/falha da execução
    "acao": str,             # ✅ Nome da ação
    "resultado": Any,        # ✅ Resultado específico (evento criado, etc)
    "resposta": str|None,    # ✅ Mensagem ao usuário
    "erro": str|None,        # ✅ Mensagem de erro
    "already_sent": bool,    # ✅ Enviado pelo transporte?
    "handled": bool          # ✅ Foi tratado?
}
```

### Semantics
- `already_sent=True`: Mensagem foi enviada pelo transporte (Telegram bot.send_message ou HTTP WhatsApp)
- `already_sent=False`: Mensagem está em `resposta`, pronta para adapter enviar
- `handled=True`: Ação foi processada, não processar novamente
- `handled=False`: Ação não foi processada
