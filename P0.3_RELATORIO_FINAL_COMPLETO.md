## 🎯 CRÍTICO: SEMÂNTICA DE `already_sent`

**Antes (ERRADO):**
```python
already_sent = update and update.message  # ❌ Não é boolean puro
```

**Depois (CORRETO P0.3):**
```python
already_sent = False  # Default
if update and update.message:
    await update.message.reply_text(mensagem)
    already_sent = True  # APENAS se enviado efetivamente

# Invariante: already_sent == bool
# Invariante: already_sent=True SOMENTE se transporte foi acionado
# Invariante: já=False → adapter deve enviar
```

**Validações:**
- ✅ `type(already_sent) == bool`
- ✅ Telegram: `already_sent=True` (já enviou via `context.bot.send_message()`)
- ✅ WhatsApp: `already_sent=False` (adapter vai enviar)
