## 🚨 CRÍTICO: DEFINIÇÃO DE `already_sent`

**P0.3 item #4 diz:**

> `already_sent=True` somente quando uma mensagem realmente foi enviada pelo canal correspondente.
> 
> NÃO usar: `already_sent=True` simplesmente porque o executor montou uma string.

**Aplicação:**

```python
# ✅ CORRETO (Telegram):
if context is not None:
    await context.bot.send_message(...)  # ← Realmente enviado
    return {"already_sent": True, ...}   # ← Mark true

# ✅ CORRETO (WhatsApp):
# No adapter WhatsApp, após envio HTTP 200
resultado_meta = await send_whatsapp_cloud_api(...)
if resultado_meta.status_code == 200:
    return {"already_sent": True, ...}   # ← Realmente enviado

# ❌ INCORRETO:
return {"already_sent": True, ...}  # Sem enviar nada
```
